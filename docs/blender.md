# Blender技巧笔记本

众所周知，建模软件Blender的使用是个循序渐进的过程，你会遇到很多问题，同时去查找这些问题的解决方案，每个解决方案又能更加增进你对Blender的了解。你对Blender的认知就是这样螺旋上升的。这个页面就是用来记录我在Blender中遇到问题，解决问题的过程中知晓的一些Blender技巧，以防止长时间不用而忘记。

之前在我的Blog里也有一篇Blender技巧记录型文章，不过那个文章主要是服务于Ballance制图的，这里记录的不局限于Ballance制图，而是面向更广泛的Blender创作的。因为给Ballance搞东西死路一条，我已经放弃了Ballance制图了，原文章的一些技巧会在这里重新组织并记录，原文章不再更新。

## 物体模式

### 快捷键

* 快速视图
    - `Numpad 0`：摄像机视角
    - `Numpad 7`：顶视图
* `F2`：选中物体重命名（和Virtools快捷键一致）
* `Ctrl + A`：打开应用（应用变换）菜单（Apply的首字母）
* `Ctrl + L`：打开数据关联和复制菜单（Link的首字母）
* `Ctrl + P`：设置父级目标/绑定。将选中的物体绑定到活动物体下方。活动物体为父。
* `Ctrl + 大键盘数字`：快速给当前选定物体添加等级为`大键盘数字`的Surface Subdivision（表面细分）修改器。例如`Ctrl + 2`就是快速添加等级为2的表面细分修改器。
* `/`：进入或退出孤立模式。孤立模式下暂时不看其它物体，只显示当前选中物体（所以它不会更改其它物体的可见性，只是暂时不看）。

## 编辑模式

### 快捷键

* 扩选与缩选
    - `Ctrl + Numpad+`：扩选一圈。这个对于选择挤出部分的侧边非常有用，挤出后立即扩选一次，即可选择到所有挤出的侧边。
    - `Ctrl + Numpad-`：缩选一圈，上面的相反操作。
* Select Linked：选择互相连接的部分
    - `L`：以鼠标所至位置为初始点，选择所有与其相接的部分。可以连续按多次`L`来选择各个独立部分。
    - `Shift + L`：`L`的相反操作，将鼠标所指位置的相接顶点从选择中删除。
    - `Ctrl + L`：类似于`L`，但是不再以鼠标位置为起始点了，改为以用户当前选择的所有结构为起始点，选择所有相接的部分。
* `v`：断离顶点，将选中的顶点断开，分裂成两个顶点。
* `M`：合并顶点菜单（合并到中心等）。
* `gg`：连按两下`g`，顶点滑移。顾名思义，选中一个顶点后按这个键可以在与其相连的任意一条边上滑移这个顶点。但似乎不能在边的延长线上滑移。
* `Alt + S`：膨胀和压缩/法向缩放，顾名思义，选中一条边，可以按照其向外还是向内的方向缩放，解决了缩放不能按局部法线进行的毛病。
* 先`E`后`S`：类似于内插面，但是是可以从没有面的部分开始。
* `Shift + E`：设置折痕，按下后拉的越远折痕越明显。这个看起来很像锐边，但实际上只有配合表面细分修改器的时候才能看出效果，因为表面细分修改器似乎对锐边处理的不太好，标记了锐边也不会锐利，此时就要使用折痕来锐利它。如果要清除折痕，可以选中有折痕数值的边，然后`N菜单 - Item - Transform - Edges Data - Mean Crease`，把它拉到0就好了。

### 曲线编辑模式专用

曲线编辑每个控制点也可以按`V`调整控制柄模式，和动画里的`Graph Editor`面板里的控制柄一致。需要注意的是Vector模式比较特殊，在使用曲线倒角时，只有Vector控制点连到其他点的中间的Segment是只会倒角一段的。其他类型由于中间是曲线，会分好多段。

曲线编辑模式中，使用`Alt + S`按键可以单独调整某个控制点附近的曲线倒角厚度，也就是可以单独设置每个控制点的粗细的意思。这实际上是操作了N面板中`Item - Transform - Radius`的数值。

## Sculpting模式

### 快捷键

* `F`：调整雕刻笔刷大小。点击后左右移动鼠标调整笔刷大小，`LMB`确定。

## Texture Paint模式

### 工具选项

Texture Paint模式的画笔，油漆桶工具，在其属性面板中有`Options - Bleed`选项。因为UV映射有一定的模糊性，所以在画贴图的时候，不能让颜色紧贴着UV边缘就结束，必须涂出去一点，才能保证不会渲染出错。这个选项就是控制涂出去的部分有多大的。这和画画中用油漆桶上色药多涂出去一点是一个道理（不然线稿和涂上去的颜色中间会有一层没有颜色的环）。

### 快捷键

* `M`：切换面遮罩模式。面遮罩模式下，只有被选择的面可以被画笔画上。
* `F`：调整画笔大小。同雕刻笔刷。

## N菜单部分

* `View - View - View Lock - Lock - Camera to View`：将摄像机视角锁定到你的视图上，移动视图也会同时移动摄像机。虽然感觉也可以进入摄像机视角后用自由移动来实现。

## 数据面板部分

### 摄像机数据

* `Viewport Diaplay - Passepartout`：摄像机非渲染部分的透明度，调成1可以让非渲染部分全变成黑色，方便观察结果。

## 布料模拟部分

布料模拟适合做垫子，沙发和窗帘等物品，先创建物体，添加布料模拟，设定好参数后，就可以播放动画来模拟，模拟到想要的地方时暂停，然后直接Ctrl + A应用布料模拟修改器即可固定下当前形状。

### 垫子与沙发

#### 沙发物体准备

新建一个立方体，进入编辑模式（我怀疑在物体模式下缩放会有Bug，最好进编辑模式），Z轴压扁，XY平面拉伸。然后纵向横向环切几次（我切了4次，不环切的话后面表面细分后的物体形状就变成圆形了）。然后加一个Subdivide Surface修改器，迭代2-3次即可，然后应用。

#### 锚固

如果沙发上有需要锚固的部分，比如沙发上那些嵌进去的纹路，需要使用顶点组功能。先选中需要锚固的顶点（一般是选线条），然后转到顶点组，新建一个顶点组，然后指定这些需要锚固的顶点，之后设置布料模拟的时候会用到这个顶点组。

#### 沙发纹路准备

新建一个平面，纵向横向各自环切相同的次数，然后使用修改器Decimate，选择Un-Subdivide模式，迭代选择一次，即可把细分好的矩形空间转成菱形形状。然后应用修改器，面模式下按A选择所有面，X选择仅删除面，保留下所有边框。

为了将纹路蚀刻到沙发上，需要使用投影切割功能。将沙发置于下方，纹路置于上方，视图转为Z轴正向，从顶往下看。然后进入沙发的编辑模式，然后再在大纲视图里Ctrl点选纹路物体。然后选择Mesh - Knife Project，即可将纹路蚀刻到沙发上。蚀刻后的图形选择的是面，可以使用Select - Select Loops - Select Boundary Loop来选择围绕这些面的边，也就选择到了蚀刻上去的纹路了，然后就可以给蚀刻上去的纹路指定顶点组了。

#### 物理模拟设置

* Stiffness硬度
    - Tension：15
    - Compression：15
    - Shear：1
* 勾选Pressure
    - Pressure：10适合沙发，小垫子大概0.5合适？
* Shape
    - Pin Group设置刚才准备好的锚固顶点组
* Field Weight
    - Gravity设置为0。也就是把重力关掉，不然跟下垂了一样。

### 动画制作流程

先是Blocking阶段。在这个阶段不需要考虑任何的插值，插值模式更改为constant。只需要在Timeline上合适的位置打上关键帧，然后做好合适的物体变换即可。这个阶段主要关注时序和位置。
Splining阶段。将先前的常数插值改为正确的插值，通常是贝塞尔曲线。
然后是Polishing阶段，主要是精细调整。例如对动画播放起来一些违和感的部分做特殊化调整。动画不是一个线性的艺术，它依靠你的主观感受，你做的细微调整越多，动画就越逼真。

### Timeline

#### 快捷键

与其它Blender面板类似，在Animation中也支持许多类似功能的快捷键：

帧标头指的是Timeline最上面你选择的帧，用蓝色方框框起来的那个数字。也可以在Timeline右上角闹钟图标的左边的框里读到。

* `G`：和3D操作一致，是移动关键帧的意思
* `S`：和3D操作一致，可以缩放关键帧，缩放是相对于帧标头的。
* `R`：与3D操作不同，不是旋转，而是选择帧类型。实际上就是选择帧显示的图标。这个图标实际上没有任何程序上的意义，只是你看着爽不爽，按自己意愿随意换的，用于更方便直观地组织你的动画。
* `Numpad 0`：把帧标头放在视图中央。
* `Numpad .`：和3D操作一致，查看当前选定的关键帧。
* `P`：按下`P`后，在时间线上选择你想要观看预览的区间，然后动画就只会在这个区间内循环播放。`Alt + P`取消预览，动画就会从头播放到尾部。点击Timeline右上角的闹钟图标也可以进行切换，闹钟启用后，右侧的开始结束帧号就是预览的开始和结束。
* `Ctrl + Home`设置动画的开始，`Ctrl + End`设置动画的结束，设定的位置是当前的帧标头。也可以在Timeline右上角的闹钟旁边的数值里调整。当闹钟未启用的时候设置的是动画本身的长度，闹钟启用时设置的就是动画预览的开始和结束。
* `Ctrl + Shift + LMB 单击一个帧`：选择帧标头之后或之前的所有关键帧（包含帧标头那帧的），选取方式取决于你是点击帧标头后方的关键帧还是前方的，点击哪一方就选择哪一侧。
* `B`：按下后鼠标左键框选，选中框内的所有关键帧。这个框选似乎是以追加的方式进行的。
* `T`：设置插值模式，决定了当前关键帧到下一个关键帧是如何插值的。

#### 菜单

* `Timeline - View - Only Show Selected`：只显示和当前选中物体关联的动画的关键帧。
* `Timeline - Playback - Sync`：控制动画播放时的行为
    - `Play Every Frame`：每一帧都播放。如果播放时左上角变红，说明Blender没法按照渲染设置中的预定义帧率进行播放，这会造成播放动画的速度慢于最终渲染出来的成品。
    - `Frame Dropping`：丢弃一些帧，以试图让播放速率匹配渲染选项中设定的帧率。会丢失细节，但是可以让你清楚地知道你动画最终渲染出来是以什么样的速度播放的。

### Graph Editor

#### 快捷键

* `X`：选择左侧通道，点击此按键，删除对应通道。
* `Shift + RMB`：放置2D游标。2D游标会生成一条额外的水平蓝线，和帧标头的线条一样。二者交点就是游标位置。
* `Shift + E`：先选择关键帧，再按，打开Keyframe Extrapolation（关键帧外推）菜单。

#### 菜单

* `Graph Editor - Snap`：吸附，默认是`Frame`
    - `Frame`：按帧吸附
    - `Second`：按秒吸附。只会吸附到整数秒的帧上。
* `Graph Editor - Pivot Point`：旋转缩放时候的原点选择。与3D视图功能一致。

#### 控制柄

Graph Editor中的每个关键帧都有一个点和两个控制柄组成，控制柄可以有不同的类型，每种类型的行为也不相同。按`V`，或者在`Graph Editor - Key - Handle`菜单中，可以为当前选中关键帧设置控制柄类型。

* Auto Clamped：这是Blender关键帧的默认控制柄模式。在纵向移动它时，他会同时调整控制柄。如果移出了在纵轴上由上一个控制点和下一个控制点的设定的值域时，控制柄立刻变得水平。这也就意味着它总是创建一条平滑的曲线，从上一帧到下一帧，不会发生过冲。
* Automatic：与Auto Clamped类似，但他不会在移动时调整控制柄，这也就意味着它可以发生过冲行为。
* Aligned：当你在Auto Clamped中试图旋转或缩放控制柄时，会自动转为这个模式。Blender不再自动为你处理控制柄，由你自己设置控制柄。Blender只保证两侧的控制柄在同一直线上。
* Free：Aligned的更进一步版本，Blender也不再保证两侧控制柄在同一直线上。使用这个类型后，曲线的一阶导数可以不连续了。也就是在一个关键帧上可以实现类似y=abs(x)的那种突变。
* Vector：与Free类似，但是Blender会自动将控制柄指向上一个或下一个关键帧的位置。一旦你手动调整了控制柄，会立刻变成Free模式。
